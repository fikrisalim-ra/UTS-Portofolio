INTERNSHIP PROJECT • GRETIVA ARTHA GROUP

Gretiva Bot — Multi-Module Telegram Automation

Developed during an internship at Gretiva Artha Group, Gretiva Bot is a Telegram-based operational assistant built on N8N that unifies internal task management, creative asset templates, broadcast messaging, and content analytics in a single conversational interface.

ROLE & CONTRIBUTION
Contributed to the development of the bot's modules and automation workflows.
Implemented Functional Modules
  • AI Chat Interaction: Conversational query handling routed through Telegram Bot API and N8N logic nodes.
  • Task Management: Two-way synchronization with Notion API workspaces for logging and tracking operational tasks.
  • Asset & Template Management: Quick retrieval of standardized digital assets and templates directly via bot commands.
  • Broadcast Functionality: Automated distribution of announcements and updates across targeted Telegram channels/users.
  • Analytics & Content Automation: Integration with Meta Instagram Graph API for content-related automation and insights retrieval.
SYSTEM ARCHITECTURE // GRETIVA BOT N8N + 3 APIs
PERSONAL PROJECT • N8N & DISCORD

Discord Automation Bot — Voice Session & Break Reminder System

A personal automation system built with N8N and Discord integrations to promote healthier digital habits during long Discord voice channel sessions by tracking active duration and sending automated break reminders.

Core Project Focus
  • Voice Channel Session Monitoring: Tracking user join, leave, and active session states across Discord voice channels.
  • Automated Break Reminders: Triggering scheduled notification prompts when continuous voice session durations reach threshold intervals.
  • Discord Bot Interactions: Handling user commands and status checks directly inside Discord channels.
  • Workflow Automation: Utilizing N8N nodes to connect Discord events, timer logic, and automated messaging without complex standalone hosting overhead.

05 // DESIGN SYSTEM CULTURAL CODEX
Visual Identity & Local Cultural Integration

The Modern Balinese Digital Aesthetic.

Rather than pasting traditional motifs everywhere like a tourism brochure or wedding invitation, this portfolio reinterprets Balinese spatial philosophy, carving geometry, and classical Kamasan natural pigments through contemporary Swiss-editorial grid discipline.

PILLAR I // SPATIAL GEOMETRY

Tri Angga & Sanga Mandala Grid

Inspired by traditional Balinese architectural zoning—Utama (header/thesis), Madya (core content matrix), and Nista (foundation/colophon)—paired with the 9-zone Sanga Mandala courtyard proportion and generous breathing room (Karang Bengang).

PILLAR II // VECTOR ORNAMENTATION

Patra Punggel & Candi Bentar Lines

Traditional Patra botanical carvings and stepped Candi Bentar split-gateway silhouettes are distilled into crisp 1.25px monoline vector strokes, stepped corner brackets (Karang Asti), and structural section dividers.

PILLAR III // MATERIAL PALETTE

Kamasan Classical Pigments

Grounded in the tactile warmth of classical Wayang Kamasan paintings on unbleached cotton (Kain Belacu), soot ink (Mangsi), burnt temple brick (Bata Merah), muted gold leaf (Prada), and volcanic sandstone (Batu Padas).
